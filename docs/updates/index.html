Hoshisora OS

Code-Updates · Alpha 001

Sechs Codepakete für bestehende Hoshisora-Testinstallationen auf Fedora 44. Diese Quelle enthält kein Designpaket und keine installierbare ISO. Sie ist kein vollständiger Installer für ein gewöhnliches Fedora-System.

Der signierte Updateweg über GitHub wurde in einer isolierten VM erfolgreich geprüft: Alle sechs bisherigen Testpakete wurden aktualisiert und anschließend verifiziert. Die Quelle bleibt eine Alpha für bestehende Testinstallationen.
